# AMALAN BAIAT v1.0

Aplikasi Android **AMALAN BAIAT**.

## Build APK tanpa Android Studio

1. Buat repository GitHub baru, misalnya `AMALAN-BAIAT`.
2. Upload **seluruh isi ZIP ini** ke repository (bukan folder ZIP di dalam repository).
3. Buka tab **Actions**.
4. Pilih workflow **Build AMALAN BAIAT APK**.
5. Tekan **Run workflow**.
6. Setelah selesai, buka hasil workflow dan bagian **Artifacts**.
7. Download `AMALAN-BAIAT-v1.0-debug`.
8. Di dalam ZIP artifact tersebut terdapat file APK untuk dipasang di Android.

Workflow juga otomatis berjalan ketika ada perubahan yang di-push ke branch `main` atau `master`.
